# Logos do TMDB

Guarde aqui os arquivos de logo do TMDB, baixados de
<https://www.themoviedb.org/about/logos-attribution>.

Regras do TMDB para o uso (resumo; vale a página oficial):

- Use o logo só para dar crédito ao TMDB, em tamanho menor que a marca do Flomo.
- Não altere cores, proporção nem o desenho do logo.
- Não sugira que o TMDB endossa ou certifica o Flomo.

Em uso: `primary-short-blue.svg` (página Sobre). Mantenha o nome original dos arquivos baixados.
